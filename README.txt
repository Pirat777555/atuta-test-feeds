Набор тестовых фидов Яндекс Недвижимость для Atuta

01_valid.xml
Корректный фид с 10 объявлениями. Использовать первым.
Проверки: обычный импорт и сохранение полной пары координат.

02_empty.xml
Корректно сформированный XML без объявлений.
Ожидание: пустой источник не должен удалить уже существующие объявления.

03_broken.xml
Намеренно оборванный/поврежденный XML.
Ожидание: ошибка парсинга; существующие объявления должны остаться.

04_missing_id.xml
У первого offer удален атрибут internal-id.
Ожидание: объявление без ID должно обрабатываться как ошибка.

05_coordinates_lat_only.xml
У первого объявления есть latitude, но нет longitude.
Ожидание: неполная пара координат должна обрабатываться как ошибка.

06_coordinates_lon_only.xml
У первого объявления есть longitude, но нет latitude.
Ожидание: неполная пара координат должна обрабатываться как ошибка.

07_mass_delete.xml
Из исходных 10 объявлений оставлено только одно, с тем же internal-id.
Использовать после успешной загрузки 01_valid.xml.
Ожидание: массовое удаление должно попасть под защиту/карантин, а не удалить объявления сразу.

Сценарий «ошибка источника / прерванная загрузка»:
Сначала успешно импортировать 01_valid.xml. Затем сделать URL источника
временно недоступным или заставить его вернуть HTTP-ошибку/оборванный ответ.
Проверить, что уже существующие объявления не удаляются.
